# Curated Place Photos

This folder is for manually collected curated photos for famous Metro Manila places.

Each famous place should have 3 real WebP images:

- `place-slug-1.webp` = place card image and first detail image
- `place-slug-2.webp` = second detail image
- `place-slug-3.webp` = third detail image

Example:

```text
intramuros/intramuros-1.webp
intramuros/intramuros-2.webp
intramuros/intramuros-3.webp
```

Use real photos only. Do not use random or misleading fallback images.

Save the source and credit information for every image in `photo-credits.template.json`.
For Creative Commons or similar licensed images, keep the source URL, author, license,
and changes made. If an image is converted to WebP, record that as a change.
